What changed and why

Goal. Re-run ConceptGraphs ViT-H-14 on the same 8 Replica scenes with our scorer and check that it reproduces its published numbers (HOV-SG Table I: mIoU 0.18, F-mIoU 0.23, mAcc 0.30, tolerance +/-0.03). If it does, the scorer is anchored to an external result.

This sub-version is the environment build. It was logged as blocked: the cluster submit failed with exit 75 (VPN down, cluster unreachable), nothing ran and no job id exists. The same setup was resubmitted later and the build succeeded; the attempt text itself was not rewritten because the attempt log is machine-written.
