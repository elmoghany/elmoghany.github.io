Baseline B02 reproduces the ATLAS Navigator (language-embedded Gaussian-splat navigation, arXiv 2502.20386) so that it can later be blended with the B01 manipulation policy. Its headline result is a set of single real-robot runs with no released data, so it cannot be re-run. The reproduction therefore runs in proxy mode: three component targets plus a closed-loop band in our own simulator, all pre-registered and frozen before any ATLAS measurement.

Not a result yet

The gate's check for B02 is not passing: pass: false, checkpoint stage PENDING, 0 distinct proxy seeds recorded. The only ATLAS record is one out-of-band seed-0 row. B02 is expected to end through a gap report and a verifier pass, not through a clean reproduction.

06

Decision rounds so far

Every change to B02's protocol goes through a written decision round by the research director; the target file itself has not been edited since 2026-10-05.

round 1

Foundation B = GR00T N1.6 on G1; comparison baselines queued; ATLAS reproduced in proxy mode.

round 2

ScanNet needs a signed ToS, so the segmentation component moves to Replica-8 with the HOV-SG scorer; ConceptGraphs re-run and a GT oracle become scorer preconditions.

round 3

Proxy target approved: bands pre-registered before any ATLAS number existed; the claim wording is fixed as 'falls in pre-registered proxy bands', never 'reproduces Table 3'.

round 4

The first oracle job (990677) was invalid (ground-truth -1 labels fed as predictions); oracle v2 defined and run once (993361); no band or tolerance changed.

round 5

G1 adaptations accepted: gravity-axis ground rule, 640x480 render processed at 256x160, official collision height kept.

round 6

G1's own torso is visible in its head camera (13.5-14.4% of pixels); self-pixels are masked identically for every agent.

round 7

Diagnosis of the Replica miss; pre-registered LOSO basis test with a fixed decision rule; HM3D 2 m / 5 m misses stand as measured.

rounds 8-9

Planner search budget runs on wall-clock time (official 0.3 s); a high fire rate is expected behaviour, not a fault.

round 10

Band throughput plan: render cadence, two-arm concurrency, a GPU-hour projection and a pre-registered fallback.

round 11

Mean-dominance test done: removing the PCA mean lifts room0 from 0.0001 to about 0.05, still far from the band; option (i) (gap report) confirmed.

07

Open items

  • Replica segmentation: ATLAS seed 0 scores 0.003. Diagnostics (b2.7) place the loss in the released 24-d PCA basis, not in our install, but no fix exists inside the pre-registered protocol.
  • HM3D memory: seeds 1-2 are being re-run on a single GPU model; the first resumed run (job 13128) reports 13.17 GiB for the 2 m setting on an RTX 6000 Ada, the 5 m run ended with return code 5 and the job is still going. Not yet interpreted.
  • Closed-loop band: 108 units (36 tasks x 3 seeds x 2 arms), projected cost under review; nothing has been recorded.
  • Videos of closed-loop G1 episodes do not exist yet.
