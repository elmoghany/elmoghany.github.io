What changed and why

ConceptGraphs is research code pinned to early-2024 library versions. Getting one scene through it required a chain of build fixes, all in our own wrapper script (cg_scene.sh) and none in ConceptGraphs itself. The attempt was logged as blocked for the first fix, because the cluster was unreachable at resubmission; the chain below is the full story.

job 997970 (L40S)

Failed after 23 s: torch 2.0.1's cpp_extension needs pkg_resources, but the env had setuptools 84. Fix: pin setuptools==69.5.1 before the GroundingDINO build (the logged b2.3 change).

job 998282 (A40)

setuptools pin worked; then invalid command 'bdist_wheel'. Fix: install wheel==0.43.0; build the GroundingDINO op CPU-only (unused for class-agnostic mode); pin transformers==4.36.2, supervision.

job 998931 (L4)

Detection died on frame 0: supervision 0.18 iterates detections as 6-tuples, ConceptGraphs expects 5. Fix: supervision==0.17.1, plus pytorch3d 0.7.4 for overlap matching, and a work-root move because pull refuses symlinks.

smoke on an allocation (RTX 3090)

3 frames detected, SLAM merged to 19 objects, export OK (60,452 points).

job 999926 (RTX 2080 Ti, 11 GB)

CUDA out of memory in SAM ViT-H automatic mask generation (needs more than 11 GB). Fix: every scene job now asks for at least 24 GB.

room0 on RTX 3090 24 GB

Completed: detection of 200 frames in 1,099 s, mapping 418 s, 81 objects, 333,300 points, 30 distinct predicted labels, bounding box matching the room mesh within centimetres.
