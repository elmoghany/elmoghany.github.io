01

What changed and why

This version runs ATLAS itself. Four things had to be fixed on the way, all outside the vendored ATLAS code:

  1. Replay clock and GPU floor. The first room0 job (9555) landed on a V100 (sm_70): the replay never became ready (simulated clock) and the image's rasterizers hang below sm_75. Replay fixed; every ATLAS job now needs compute capability at least 7.5 and 32 GB.
  2. Container module path. Job 9718 passed replay (200/200 frames, 2 submaps, 446,594 Gaussians) but the label stage could not find apptainer in a batch shell; the script now sources the module system.
  3. Label-stage memory. All eight scene jobs then died in the label step: a broadcast cosine similarity of 200,000 points x 102 classes x 512 dims needs 38.9 GiB. Replaced with the same two normalisations plus a chunked matrix product (max |difference| at most 6e-7 against the original on random tests, 0 of 4,096 mismatches in-job), and a fail-closed label-only resume.
  4. Scoring and memory runs. One CPU scoring job for all eight scenes (10172) and three HM3D walks (10179, 10197, 10223).
Result: out of band, not recorded as a pass

ATLAS mIoU 0.003 (band 0.12-0.19), relative to ConceptGraphs -0.181 (band -0.05 to +0.03). All scorer preconditions were in band in the same invocation, and geometry is fine (median alignment about 2 cm), so the near-zero score points at the feature-to-label path, which is investigated in b2.7.

Setup

code
atlasnav @ 1f5c4af6, vendored unmodified; new wrapper scripts under scripts/ only
replay
lockstep replay of NICE-SLAM frames through the official ROS node: stride 10, GT poses, tracking off, language on, official submaps; the exported map merges all submaps and logs the count per submap
text encoder / labels
MaskCLIP head, open_clip ViT-B-16 laion2b_s34b_b88k (512-d); features decoded from the 24-d map feature with ATLAS's own formula (feature @ V + mean), HOV-SG prompt templates, cosine arg-max over the 102 Replica classes
jobs
replays 9745-9802, labels 9892-10097, scoring 10172, memory 10179 / 10197 / 10223; code tags v0.2.163 to v0.2.166
not run
Replica seeds 1 and 2 (the director ruled that a 40x miss with every precondition passing does not need a seed spread)
